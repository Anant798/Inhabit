# Inhabit AI - React Frontend Foundation

Professional voice-controlled interior design workspace for Unreal Engine integration.

## Setup Instructions

```bash
cd inhabit-frontend
npm install
npm run dev
```

## Features
- Minimalist and sophisticated UI layout matching interior design software standards.
- Browser-based Speech-to-Text using the Web Speech API (`window.SpeechRecognition`).
- 3D Viewport placeholder ready for Unreal Engine Pixel Streaming integration.
- Object properties panel for transforming 3D scene objects.
- Command history tracking with success/failure indicators.
- Future-proof modular architecture.
